# SSToolbox для pyRevit

Расширение для Revit 2024 и IronPython 2.7.12. Команды расширения находятся на вкладке «SSToolbox».

## Подключение

1. Поместите рабочую копию репозитория в папку `SSToolbox.extension`. В корне этой папки должна находиться `LowVoltage.tab`.
2. Добавьте родительскую папку `SSToolbox.extension` в список путей расширений pyRevit. Из родительской папки можно выполнить `pyrevit extensions paths add (Get-Location).Path` в PowerShell.
3. Запустите Revit 2024 или нажмите `Reload` на вкладке pyRevit, если Revit уже запущен.

## Обновление

Codex в ChatGPT редактирует исходники прямо в рабочей копии. После локальных правок нажмите `Reload` и проверьте кнопку. Для просмотра изменений выполните `git status` и `git diff` в папке расширения.

В русской версии pyRevit две кнопки могут называться «Обновить». Для
локальных правок используйте ту, чья подсказка начинается с «Находит папки
со скриптами». Она заново загружает панели. Можно также перезапустить Revit.
Кнопка с подсказкой «Скачивает обновления из удаленного git репозитория»
обращается к Git. Если в локальном репозитории ещё нет первого коммита,
эта кнопка может завершиться ошибкой `NoneType ... Id`; для загрузки
локальных файлов первый коммит не нужен.

Если рабочая копия подключена к удалённому репозиторию, изменения с другого компьютера можно получить командой `git pull --ff-only`, а затем нажать `Reload` в Revit.

## Создать цепи

После подключения или обновления расширения откройте в Revit 2024 вид с нужными
элементами и нажмите **SSToolbox → Цепи → Создать цепи**. Команда
показывает число найденных групп «панель — нагрузка» и предлагает подтвердить
создание. Обрабатываются экземпляры на активном виде в текущем проекте; выбор
элементов и связанные модели не учитываются. Dynamo не требуется.

- Панель: электрооборудование с заполненным `SMNX_Адрес устройства`, с
  `SMNX_Комплект`, содержащим `СПА`, и с заполненным `SMNX_Имя нагрузки`.
  В имени нагрузки панели можно перечислить несколько значений через запятую
  с пробелом. Электрооборудование с адресом рассматривается только как панель.
- Устройство: экземпляр электрооборудования без адреса либо осветительного
  прибора, электрического прибора, устройства охранной или пожарной сигнализации,
  устройства вызова и оповещения. Его `SMNX_Имя нагрузки` должно совпадать
  с одним из имён панели целиком, с учётом регистра.
- Для обычной панели создаётся одна цепь на имя нагрузки из подходящих
  неподключённых устройств. Если у устройств несколько общих типов коннекторов,
  команда выбирает `Controls`, когда он общий; при другом неоднозначном выборе
  группа пропускается с ошибкой. Для панели, имя которой начинается с `MD.`,
  каждый подходящий коннектор получает свою цепь, до двух на устройство к этой панели.
  Если Revit не сообщает тип свободного коннектора, используется тип из настроек
  (по умолчанию `Controls`, как в графе). Совместимость проверяет Revit.
- Существующие цепи не изменяются. Повторный запуск учитывает подключения
  к каждой панели, в том числе вне активного вида. Для новых устройств с тем же
  именем может быть создана новая цепь. Если имя нагрузки совпадает у нескольких
  панелей, панели обрабатываются по возрастанию ID, пока у устройств есть
  свободные коннекторы.

Имя записывается во встроенный параметр цепи «Имя нагрузки», а если он недоступен —
в одноимённый пользовательский параметр из настроек (по умолчанию
`SMNX_Имя нагрузки`), если он есть на цепи и доступен для записи.
При ошибке создания, назначения панели или записи имени отдельная цепь
откатывается. Результат и причины пропусков видны в отчёте pyRevit. Успешные
изменения команды можно отменить одним действием.

**Shift+клик** открывает настройки имён параметров, фильтра комплекта, префикса
панели и запасного типа цепи. Настройки сохраняются в конфигурации pyRevit.

Перед применением к рабочей модели проверьте на тестовом проекте:
обычная панель с несколькими устройствами в одной цепи, панель `MD.` с двумя
коннекторами у одного устройства, повторный запуск, несовместимая панель,
устройство без свободного коннектора, пустой вид и отказ от подтверждения.
